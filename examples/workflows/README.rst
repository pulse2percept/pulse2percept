Key examples
============

Start here, in this order:

1. :ref:`sphx_glr_examples_workflows_plot_argus_video.py`: images, video,
   and encoders on an epiretinal implant.
2. :ref:`sphx_glr_examples_workflows_plot_amd_prima.py`: a photovoltaic
   implant inside a scotoma, with scenes, gaze, and both eyes.
3. :ref:`sphx_glr_examples_workflows_plot_dynaphos.py`: a cortical implant
   and phosphene dynamics over time.
4. :ref:`sphx_glr_examples_workflows_plot_data_beyeler2019.py`: model
   predictions against measured phosphene drawings.
